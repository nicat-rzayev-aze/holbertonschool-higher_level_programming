The `5-text_indentation` module

Using `text_indentation`


Importing the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Normal text validation:
    >>> text_indentation("Hello. World? Testing: Python.")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Testing:
    <BLANKLINE>
    Python.
    <BLANKLINE>

Checking spaces removal at beginning and end of lines:
    >>> text_indentation("   Sentence one.    Sentence two?   ")
    Sentence one.
    <BLANKLINE>
    Sentence two?
    <BLANKLINE>

Error: text is not a string (TypeError):
    >>> text_indentation(12345)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string
