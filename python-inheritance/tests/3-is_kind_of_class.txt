The `is_kind_of_class` function checks for instances and sub-classes.

To test the function, first import it:
    >>> is_kind_of_class = __import__('3-is_kind_of_class').is_kind_of_class

Test with an integer:
    >>> a = 1
    >>> is_kind_of_class(a, int)
    True
    >>> is_kind_of_class(a, float)
    False
    >>> is_kind_of_class(a, object)
    True

Test with a custom inherited class:
    >>> class MyList(list):
    ...     pass
    >>> my_list = MyList()
    >>> is_kind_of_class(my_list, MyList)
    True
    >>> is_kind_of_class(my_list, list)
    True
