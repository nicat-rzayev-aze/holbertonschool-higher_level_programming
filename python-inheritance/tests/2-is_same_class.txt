The `is_same_class` function checks for the exact type match.

To test the function, first import it:
    >>> is_same_class = __import__('2-is_same_class').is_same_class

Test with an integer:
    >>> a = 1
    >>> is_same_class(a, int)
    True
    >>> is_same_class(a, float)
    False
    >>> is_same_class(a, object)
    False

Test with a string:
    >>> s = "Hello"
    >>> is_same_class(s, str)
    True
    >>> is_same_class(s, object)
    False

Test with boolean (bool inherits from int, so exact check must be False for int):
    >>> b = True
    >>> is_same_class(b, bool)
    True
    >>> is_same_class(b, int)
    False
